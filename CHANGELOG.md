# Changelog

This project does not maintain a hand-written changelog file. Every merge to `main` that changes `sync-ssh-keys.sh` or `users.conf` is automatically tagged and published as a [GitHub Release](https://github.com/locus313/ssh-key-sync/releases) with auto-generated release notes (see `.github/workflows/release.yml`).

For a full history of changes, see the [Releases page](https://github.com/locus313/ssh-key-sync/releases).
